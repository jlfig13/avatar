# apps/client/public/assets

Assets **exportados** e servidos ao navegador: spritesheets/atlas (`.png` + `.json`), mapas do Tiled (`.tmj`) e áudio. As fontes (`.aseprite`, projetos do Tiled etc.) ficam em `assets-src/` na raiz (ADR-022).

Arquivos binários passam pelo Git LFS — veja `assets-src/README.md` para instalar e configurar.
